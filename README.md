# Compny

VS Code inline code completion using the OpenAI Responses API.

1. Open the **Compny** icon in the activity bar, or run **Compny - Configure OpenAI** from the Command Palette.
2. Enter the Responses API endpoint, model name and API key, then save. The key is stored in VS Code Secret Storage.
3. Type in an editor to receive suggestions, or press `Alt+\` to trigger one manually.

The sidebar can also toggle automatic suggestions. Other completion options are available in VS Code settings under `compny`.

Compny is based on [twinny](https://github.com/twinnydotdev/twinny) and retains its MIT license.
